Rarvon for desktop (beta), for Linux
====================================

Start Rarvon:            ./rarvon
Add it to your menu:     ./install.sh
Remove it from the menu: ./install.sh --remove

Rarvon opens in an app window of Chromium, Google Chrome, Microsoft Edge, Brave
or Vivaldi if one is installed, otherwise in a tab of your default browser.
It closes by itself shortly after you close its window.

On Debian, Ubuntu or Fedora, the .deb or .rpm package is easier: it adds Rarvon
to the menu for everyone and installs updates the usual way.
